    22 — 第 1 阶段 — 网络呈现、频道信息和通知¶

    目标¶

    连接在线状态指示器，在成员列表之外添加频道信息面板，实现应用内通知 toast 和浏览器通知，并添加加载/空状态 UI — 完成 Web 客户端的实时感知和反馈循环。

    范围¶

    在线状态¶

    • 订阅ChatRoute中的presence.updated WS事件。
    • 更新每个事件的usePresenceStore (onlineUserIds: Set<string>)。
    • 将成员列表中的角色色点替换为在线状态点：
    • 绿点=在线。
    • 灰点 = 离线。
    • 保留现有的 DM/禁止悬停操作。
    • 在会员姓名旁边显示“在线”/“上次查看 X”文本。
    • DM 标头显示对等点的在线状态。
    • 在 WebSocket 连接上发出 presence.update（使用 status: "online"）。

    频道信息面板¶

    • 增强会员列表之外的现有右侧边栏：
    • 频道/DM 名称（可由管理员编辑）。
    • 频道描述/主题文本。
    • 会员数量。
    • 创建日期。
    • 通道模式徽章（正常/E2E）。
    • 对于 E2E 通道：安全信息部分（加密状态、设备数量）。
    • 面板中的选项卡或部分：信息/成员。
    • 关闭按钮以关闭面板。

    通知 Toast¶

    • 集成 sonner 用于 toast 通知（轻量级、Tailwind 兼容）。
    • 当新消息到达非活动频道时进行提示：“{sender}: {preview} in #{channel}”。
    • 单击 toast → 导航至该频道。
    • 后台选项卡的浏览器通知 API 后备：
    • 请求登录时的通知权限。
    • new Notification("Nexus Chat", { body, icon }) 传入消息。
    • 限制：每秒最多 1 个 toast，以避免通知风暴。

    加载状态¶

    • 初始加载期间消息列表上的骨架屏幕（脉冲占位符行）。
    • 工作区获取期间通道列表上的骨架。
    • 刷新期间进行身份验证验证的微调器。

    空状态¶

    • “还没有消息——打个招呼！”在空通道中带有友好的插图。
    • “没有加入频道。请向管理员请求邀请。”在空的工作空间中。
    • 空会员/频道搜索“无结果”。
    • 当没有频道处于活动状态时，“选择一个频道开始聊天”。

    连接状态¶

    • 改进标头中现有的 WS 断开连接徽章：
    • 重新连接期间“正在连接...”（黄色）。
    • “已连接”（绿色）— 2 秒后自动关闭。
    • “已断开连接”（红色），点击重试。

    非目标¶

    • 没有打字指示器返工（已经实施）。
    • 没有已读回执返工（已实施）。
    • 无通道静音 UI（需要后端 - 任务 24）。
    • 每次聊天没有自定义通知声音。
    • 没有通知例外设置。
    • 没有“请勿打扰”模式。

    后端依赖¶

    已支持的状态事件： - presence.update 客户端事件 - presence.updated服务器事件 - usePresenceStore 已定义 onlineUserIds

    部分存在频道信息字段——Channel类型包括name、createdAt、mode、isPrivate。描述字段需要后端添加 - 请参阅任务 24。

    验收标准¶

    • [ ] 成员列表项目上的绿色/灰色在线状态点。
    • [ ] 在 DM 标头中显示对等用户的在线状态。
    • [ ] 频道信息面板显示名称、模式、成员数量、创建日期。
    • [ ] 当消息到达非活动频道时，会出现 Toast 通知。
    • [ ] 单击 Toast 导航至频道。
    • [ ] 为后台选项卡发送浏览器通知（授予权限后）。
    • [ ] 在初始数据获取期间骨架加载占位符。
    • [ ] 频道、工作区和搜索结果的友好空状态。
    • [ ] 连接状态横幅以颜色显示正在连接/已连接/已断开连接。
