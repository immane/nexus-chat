    25 — 第 1 阶段 — TUI 聊天界面重新设计¶

    目标¶

    将 TUI 交互式聊天从单列堆栈重新设计为带有状态栏的两窗格布局，反映了 Web 客户端架构。使用相对时间戳、日期分隔符、发件人显示名称和键盘驱动的消息操作改进消息显示。添加针对编辑、删除、反应、键入指示器和状态的实时 WebSocket 响应能力。

    范围¶

    布局和导航¶

    • 使用固定的两窗格布局将当前的单列应用程序替换为 ChatShell 编排器：
    • 左窗格（侧边栏，~25–30 列）：频道/DM 列表、搜索、选项卡栏（聊天/成员/设置）。
    • 右窗格（主面板）：ChatHeader + 可滚动的 MessageArea + Composer。
    • TopBar：项目名称、WebSocket 连接状态、当前用户。
    • BottomBar：当前频道、动态状态、上下文相关的键盘快捷键提示。
    • 实现 useTerminalSize 钩子来计算终端列的窗格宽度。
    • 添加 useFocus 挂钩来跟踪哪个面板处于活动状态并启用每个面板的键盘调度。

    频道侧边栏增强功能¶

    • 通过获取GET /api/v1/workspaces/:id/members和缓存Map<userId, name>来解析发件人显示名称。
    • 显示 useChannelStore 或本地地图中每个频道的未读计数。
    • 添加带有 Ctrl+1/2/3 快捷方式的选项卡栏（聊天/成员/设置），与 Web 客户端的左侧边栏选项卡相匹配。
    • 成员选项卡：列出带有在线/离线状态点 (●/○) 的工作区成员。
    • 设置选项卡：基本用户信息和令牌状态。

    消息显示¶

    • 渲染发件人姓名而不是原始 userId。
    • 显示相对时间戳（“3 分钟前”、“2 小时前”、“昨天”），并在悬停/焦点时显示完整时间戳。
    • 当消息跨越日历日边界时插入日期分隔符 (──── Yesterday ────)。
    • 设置message.editedAt时显示(edited)标记。
    • 在消息正文下方渲染反应表情符号+计数；以青色突出显示当前用户的反应。
    • 使用上下文原因文本呈现墓碑消息。
    • 将附件元数据显示为 📎 filename (size)。
    • 支持通过↑/↓移动消息焦点；焦点行以 > 前缀突出显示。

    消息操作（键盘驱动）¶

    • 回复 (r)：在编辑器上方显示回复预览；发送时附加 replyToMessageId。
    • 编辑 (e)：仅自己的文本类型消息；进入编辑模式并预先填充原始文本。
    • 删除 (d)：仅自己的消息；叠加确认。
    • 复制 (c)：将消息文本写入剪贴板/标准输出。
    • 转发 (f)：覆盖通道选择器； POST 转发 API。
    • React (+)：提示输入表情符号；发布/删除反应 API。
    • 所有操作都与 REST 调用的 useMessageActions 式挂钩集成。

    作曲家增强¶

    • 多行输入：Enter用于发送，Ctrl+Enter用于换行；高度增加到 5 行。
    • 提示中的E2E通道指示符（[E2E]前缀）。
    • 编辑模式：预填充文本，Esc取消。
    • 回复模式：回复输入上方的预览行。
    • 在输入活动上发送 typing.start / typing.stop WS 事件。
    • 检测 bot 命令调用的 / 前缀。

    WebSocket 事件扩展¶

    扩展 lib/ws-client.ts 以侦听 message.created 之外的所有服务器 WS 事件：

    活动 行为
    message.created 附加到消息列表（现有）。
    message.updated 替换列表中匹配的消息。
    message.deleted 换成墓碑。
    message.reaction 更新本地反应图。
    message.read 更新已读回执计数。
    typing.updated 更新打字用户地图；显示在 ChatHeader/BottomBar 中。
    presence.updated 更新在线用户集。
    channel.created 将频道附加到侧边栏。
    dm.created 将 DM 附加到侧边栏。

    消息滚动和分页¶

    • PgDn/PgUp 用于页面导航。
    • Home/End 跳转到最新/最旧的消息。
    • 滚动到顶部触发器 GET /api/v1/channels/:id/messages?cursor=... 以加载早期历史记录（每页 50 条消息）。
    • 新收到的消息自动滚动到底部。

    覆盖系统¶

    • 转发频道选择器：列出带有搜索过滤器的频道； Enter 确认。
    • 删除确认：Delete this message? [Y/n]。
    • 反应输入：Enter emoji: _。
    • 所有覆盖均通过 Esc 取消。

    键盘快捷键¶

    全球¶

    关键 行动
    Ctrl+Q 退出
    Ctrl+L 焦点侧边栏
    Ctrl+M 焦点留言区
    Ctrl+I 焦点作曲家
    Tab 循环焦点
    Esc 返回/关闭叠加

    侧边栏¶

    关键 行动
    ↑/↓ 导航频道
    Enter 进入频道
    n 新频道
    Ctrl+F 搜索频道

    留言区¶

    关键 行动
    ↑/↓ 移动消息焦点
    PgDn/PgUp 向上/向下翻页
    Home/End 跳转最新/最旧
    r 回复
    e 编辑
    d 删除
    c 复制
    f 转发
    + 添加反应

    作曲家¶

    关键 行动
    Enter 发送
    Ctrl+Enter 换行
    Esc 取消编辑/回复模式

    非目标¶

    • 没有文件上传或图像渲染（终端限制）。
    • 没有右键单击上下文菜单（而是键盘快捷键）。
    • 无虚拟滚动（墨水限制；使用分页代替）。
    • 交互式聊天中没有 E2E 加密集成（推迟；信号外观已可用，但发送路径当前发送明文）。
    • 没有桌面通知（终端铃声\a可能是未来的补充）。
