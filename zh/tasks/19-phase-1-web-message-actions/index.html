    19 — 第 1 阶段 — Web 消息操作和上下文菜单¶

    目标¶

    Enable common message interactions (reply, forward, copy, delete, edit, react) through a right-click context menu and per-message action buttons, filling the biggest UX gap between Phase 1 Web and production IM clients.

    范围¶

    上下文菜单¶

    • 右键单击（桌面）/长按（移动/触摸）消息可打开上下文菜单。
    • 菜单项：
    • 回复 — 打开输入上方的回复栏，并带有引用的消息预览。
    • 复制文本 — 将消息纯文本复制到剪贴板 (navigator.clipboard.writeText)。
    • 向前 — 打开向前目标选择器（通道/DM 选择器）。
    • 编辑 — 仅适用于自己的消息；将消息文本移动到编辑输入中。
    • 删除 — 确认对话框，然后通过后端软删除。
    • React — 打开锚定到消息的表情符号反应选择器。

    回复 引用¶

    • Click Reply in context menu → a reply bar appears above message input showing a compact preview of the quoted message (sender name + truncated text).
    • 输入可选地发送 replyToMessageId 引用（一旦后端准备就绪；请参阅任务 23）。
    • 回复消息上的视觉指示器（单击时突出显示/滚动到）。
    • 回复栏上的“X”按钮可取消。

    转发¶

    • 单击前进 → 模式/下拉列表显示频道 + DM 列表。
    • 支持搜索/过滤。
    • 选择时，调用 messageService.forward 后端并导航到目标频道。
    • 转发的邮件显示“转发”标签+原始发件人属性。

    复制¶

    • 单击复制文本 → 剪贴板写入 + 简短提示“已复制”。
    • 对于端到端密文消息，禁用复制（密文没有意义）。

    编辑¶

    • 仅针对自己的短信（不是密文，不是机器人消息）。
    • 将内联消息切换到可编辑文本区域或打开模式。
    • 提交时，调用messageService.edit。
    • 在已编辑的消息上显示“已编辑”标签。

    删除¶

    • 确认对话框：“删除此消息？”
    • 确认后，调用messageService.softDelete。
    • 消息在列表中呈现为墓碑。

    反应¶

    • 每条消息下方的快速反应栏显示常用的表情符号 (👍❤️😄😢😮)。
    • “+”按钮打开完整的表情符号反应选择器。
    • 现有反应显示为表情符号 + 计数徽章。
    • 单击现有反应进行切换（添加/删除）。
    • 通过message.reaction WS事件实时反应更新。

    非目标¶

    • 无密钥验证 UI（第 3 阶段）。
    • 无消息固定 UI（需要后端固定支持 - 任务 23）。
    • 无翻译消息（需要外部翻译 API）。
    • 无时间表消息（第 2 阶段）。
    • 没有语音/视频附件录制。

    后端依赖¶

    已支持所有消息 CRUD 操作（编辑、删除、转发、反应）： - apps/server/src/domain/messages/service.ts - message.reaction、message.updated、message.deleted WS 事件 - 共享模式中的 reactMessageSchema、editMessageSchema、forwardMessageSchema

    回复 (replyToMessageId) 需要后端架构扩展 — 请参阅任务 23。

    验收标准¶

    • [ ] 右键单击上下文菜单，包含回复、复制、转发、编辑、删除、反应选项。
    • [ ] Copy 将带有 Toast 反馈的消息文本写入剪贴板。
    • [ ] 编辑切换内联编辑模式；提交给messageService.edit。
    • [ ] 删除显示确认对话框；软删除后呈现的墓碑。
    • [ ] 快速反应栏，带有 5 个默认表情符号 + 完整选择器切换。
    • [ ] 反应徽章通过实时 WS 更新呈现每条消息。
    • [ ] 回复栏显示输入上方引用的消息预览。
    • [ ] 正向模式允许选择通道/DM 目标。
