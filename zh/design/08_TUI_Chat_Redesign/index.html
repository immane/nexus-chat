    08 — TUI 聊天重新设计¶

    基于：Web 客户端架构和 OpenCode TUI 布局参考。 创建时间：2026-07-08

    1. 目标¶

    将 TUI 交互式聊天 (apps/tui/src/app.tsx) 从单列堆栈重新设计为带有状态栏的固定两窗格布局，镜像 Web 客户端的侧边栏 + 消息区域拆分。视觉风格参考了 OpenCode 的文件树 + 编辑器布局。

    2. 目标布局¶

    ┌──────────────────────────────────────────────────────────┐
│  Nexus Chat                    WS: connected   alice@t   │  ← TopBar
├──────────────┬───────────────────────────────────────────┤
│ Channels (5) │  # general                    [3 online]  │  ← ChatHeader
│ [Search...]  │                                           │
│              │  Alice  10:30                             │
│ # general (3)│  Hello world!                             │
│ # random     │  👍 2                                     │
│ @ Bob   [E2E]│                                           │
│ @ Carol [E2E]│  Bob  10:31                               │
│              │  Hey!                                     │
│              │                                           │
│              │  ──── Yesterday ────                      │
│              │                                           │
│ [Chat] [Mbr] │                                           │
├──────────────┴───────────────────────────────────────────┤
│ > Type a message...                          Enter send  │  ← Composer
└──────────────────────────────────────────────────────────┘
│ #general │ Alice typing... │ r=Reply e=Edit d=Delete     │  ← BottomBar

    3. 组件树¶

    <ChatShell>                              // Full-screen container (flexDirection="column")
├── <TopBar />                           // Title + WS status + username
├── <Box flexDirection="row" flexGrow={1}>  // Main area (row layout)
│   ├── <Sidebar width={28}>             // Left pane
│   │   ├── <SidebarHeader />            // "Channels (N)" + search input
│   │   ├── <ChannelList />              // Scrollable list with focus
│   │   └── <SidebarTabs />              // [Chat] [Members] [Settings]
│   └── <MainPanel flexGrow={1}>         // Right pane
│       ├── <ChatHeader />               // #channel + typing + online count
│       ├── <MessageArea />              // Scrollable messages with focus
│       └── <Composer />                 // Input bar with mode awareness
├── <BottomBar />                        // Status: shortcuts / typing / current channel
└── <Overlay />                          // Modal layer: forward picker, delete confirm, reaction input

    4. 窗格详细信息¶

    4.1 顶部栏¶

    ┌──────────────────────────────────────────────────────────┐
│  Nexus Chat                    WS: connected   alice@t   │
└──────────────────────────────────────────────────────────┘
    • 左：项目名称（青色粗体）。
    • 右：WebSocket 连接指示器（绿色 ● connected / 红色 ● disconnected） + 当前用户电子邮件。
    • 通过borderStyle="single"的底部边框。
    • 高度：1 行。

    4.2 侧边栏（左窗格）¶

    ┌──────────────┐
│ Channels (5) │  ← Header with count
│ [Search...]  │  ← Filter (Ctrl+F to focus)
│              │
│ # general (3)│  ← Green prefix, unread count, bold if active
│ # random     │
│ @ Bob   [E2E]│  ← Cyan prefix for DM, yellow [E2E] tag
│ @ Carol [E2E]│
│              │
│ [💬 Chat   ] │  ← Tab bar
│ [👥 Members] │
│ [⚙ Settings] │
└──────────────┘
    • 宽度：Math.min(30, Math.floor(termColumns * 0.25))。
    • 频道列表：
    • # 绿色表示正常通道，@ 青色表示 DM。
    • 黄色 E2E 标签。
    • 未读计数呈绿色(N)。
    • 活动通道突出显示（粗体+背景）。
    • ↑/↓ 用于导航，Enter 用于选择。
    • 标签栏 (Ctrl+1/2/3):
    • Chat：频道列表（默认）。
    • Members：带有在线状态点的工作区成员列表（●/○）。
    • Settings：主题、通知、令牌信息。
    • 通过 borderStyle="single" 的右边框。

    4.3 聊天标题¶

    │  # general                    [3 online] │
    • 左：# channelName（或@ DMName），带有可选的黄色[E2E]标签。
    • 右：在线会员数[N online]。
    • 当有人输入时： Alice is typing... 替换正确的部分。
    • 高度：1 行。

    4.4 消息区¶

    │  Alice  10:30                             │
│  Hello world!                             │
│  👍 2                                     │
│                                           │
│  ──── Yesterday ────                      │
│                                           │
│  Alice  Yesterday 15:22                   │
│  Old Message...              (edited)     │
    • 发件人：蓝色粗体（自身：黄色）。
    • 时间戳：灰色，相对（“3m 前”）。
    • 身体：白色。
    • 编辑标记：灰色(edited)。
    • 反应：表情符号 + 正文下方行中的计数 (👍 2 ❤️ 1)。用户自己的反应以青色显示。
    • 日期分隔符：居中──── Yesterday ────。
    • 墓碑：灰色~ Message deleted ~。
    • 附件：📎 report.pdf (2.3MB) 文本标记。
    • 滚动：
    • ↓/↑：将焦点移至一条消息。
    • PgDn/PgUp：向上/向下翻页。
    • Home/End：跳转到最新/最旧的。
    • 滚动到顶部触发器 GET /api/v1/channels/:id/messages?cursor=... 进行分页。
    • 新收到的消息自动滚动到底部。
    • 消息焦点：突出显示的行，前缀为 >。当消息聚焦时，底部栏会显示可用的操作。

    4.5 作曲家¶

    ├───────────────────────────────────────────┤
│ > Type a message...              Enter ⏎  │
└───────────────────────────────────────────┘
    • 提示>，然后输入文本。
    • 空时的占位符（灰色）。
    • 右侧提示：Enter ⏎（或Ctrl+Enter换行符）。
    • E2E渠道：提示前的[E2E]前缀。
    • 编辑模式：预填充原始文本、占位符Editing...。
    • 回复模式：输入上方的Replying to {sender}: {snippet}行。
    • 多行：Ctrl+Enter用于换行；高度增加到 5 行。
    • 顶部边框分隔符。

    4.6 底部栏¶

    │ #general │ Alice typing... │ r=Reply e=Edit d=Delete  │
    • 左：当前频道名称。
    • 中心：动态状态或打字指示器。
    • 右：键盘快捷键提示（取决于焦点面板的上下文）：
    • 消息区域聚焦：r=Reply e=Edit d=Delete c=Copy f=Forward +=React
    • 侧边栏聚焦：↑↓=Nav Enter=Select n=NewChannel Esc=Back
    • 顶部边框分隔符。

    4.7 叠加¶

    • 正向模式：带有搜索的居中频道列表； Enter 确认，Esc 取消。
    • 删除确认：Delete this message? [Y/n]。
    • 反应输入：Enter emoji: _。
    • 成员面板：当“成员”选项卡处于活动状态时替换侧边栏内容。

    5. 数据流¶

    单一编排器 (ChatShell)，类似于 Web ChatRoute：

    ChatShell
  ├── useTerminalSize()      → { columns, rows }
  ├── useChannelData()       → { channels, members, activeChannel, senderNames }
  ├── useMessages()          → { messages, send, edit, delete, react, forward }
  ├── useKeyboard()          → global shortcuts + panel dispatch
  ├── useFocus()             → { activePanel, focusedIndex }
  │
  ├──→ Sidebar:       channels, activeChannel, onSelect, focusState
  ├──→ ChatHeader:    activeChannel, typingUsers, onlineCount
  ├──→ MessageArea:   messages, focusedIndex, onAction(r/e/d/c/f/+)
  ├──→ Composer:      draft, onSubmit, editMode, replyTo
  ├──→ TopBar:        wsStatus, currentUser
  ├──→ BottomBar:     activeChannel, shortcutHints
  └──→ Overlay:       modalType, modalData

    6.WebSocket 事件¶

    扩展 ws-client.ts 以侦听所有服务器事件，而不是仅侦听 message.created：

    活动 处理程序
    message.created 在消息列表中追加/删除重复项
    message.updated 替换列表中的消息
    message.deleted 替换为墓碑
    message.reaction 更新反应图
    message.read 更新已读回执计数
    typing.updated 更新打字用户地图
    presence.updated 更新在线状态集
    channel.created 将频道附加到侧边栏
    dm.created 将 DM 附加到侧边栏

    7. 键盘快捷键¶

    全球¶

    关键 行动
    Ctrl+Q 退出
    Ctrl+L 聚焦左侧边栏
    Ctrl+M 焦点留言区
    Ctrl+I 焦点作曲家
    Tab 循环对焦面板
    Esc 返回/关闭叠加

    侧边栏（重点）¶

    关键 行动
    ↑/↓ 导航频道
    Enter 进入频道
    n 新频道
    Ctrl+F 搜索频道
    Ctrl+1/2/3 切换选项卡（聊天/成员/设置）

    消息区域（重点）¶

    关键 行动
    ↑/↓ 移动消息焦点
    PgDn/PgUp 向上/向下翻页
    Home/End 跳转最新/最旧
    r 回复
    e 编辑（仅限自己的文本类型）
    d 删除（仅限自己，确认）
    c 复制文字
    f 转发
    + 添加反应

    作曲家（重点）¶

    关键 行动
    Enter 发送
    Ctrl+Enter 换行
    Esc 取消编辑/回复模式

    9. 实施步骤¶

    步骤 描述 预计。时间
    1 基本布局：ChatShell 带有 TopBar、Sidebar、MainPanel、BottomBar； useTerminalSize 30 分钟
    2 增强频道列表：显示名称、未读计数、选项卡栏框架、突出显示行 30 分钟
    3 消息区重写：焦点系统、相对时间、日期分隔符、滚动+分页 45 分钟

    5 消息操作：通过 REST API 回复、编辑、删除、反应、转发；叠加模态 45 分钟
    6 Composer 增强：多行、打字指示器、机器人命令检测 30 分钟

    总计：约 3 小时
