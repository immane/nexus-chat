    封闭测试清单¶

    更新时间：2026-07-05

    验证流程¶

    • [x] 使用 Argon2id 哈希注册电子邮件/密码
    • [x] 登录返回 JWT 访问 + 刷新令牌 (RS256)
    • [x] 令牌刷新端点重新颁发有效令牌
    • [x] 无效/过期的令牌被 401 拒绝
    • [x] 身份验证端点的速率限制（每个 IP 10 个请求/15 分钟）
    • [x] 会话保留在 Redis（生产）或内存（开发）中

    普通频道¶

    • [x] 具有所有者/成员角色的工作区创建
    • [x] 具有会员管理功能的公共和私人频道
    • [x] 频道创建、重命名、存档
    • [x] 使用状态机发送短信（草稿 → 已发送 → 已发送 → 已读）
    • [x] 消息分页（基于光标）
    • [x] 消息中的表情符号反应
    • [x] 消息中的 Markdown 渲染

    直接消息¶

    • [x] 两个用户之间创建的 DM 通道
    • [x] DM 消息传递和分页
    • [x] DM 频道默认标记为私有

    E2E 加密 DM¶

    • [x] 1:1 DM 的信号协议 X3DH 密钥交换
    • [x] 双棘轮前向保密
    • [x] PreKeyBundle上传和检索流程
    • [x] 服务器仅存储密文（无明文访问）
    • [x] 机器人被排除在端到端渠道之外
    • [x] 斜线命令在 E2E 通道中被拒绝
    • [x] 只读/消失消息策略支持

    机器人命令¶

    • [x] 使用不透明令牌注册机器人
    • [x] 普通通道中的斜线命令路由
    • [x] 用于机器人调度的 Redis Streams 事件总线
    • [x] BullMQ 任务队列与每个机器人隔离
    • [x] 捆绑机器人：欢迎、帮助、通知

    TUI 烟雾命令¶

    • [x] 通过 TUI 登录/注销
    • [x] 工作区列表并选择

    • [x] E2E DM消息发送和验证
    • [x] 斜杠命令调用
